# POS Liquor Retail Client

A modern Point of Sale (POS) and inventory management frontend for liquor retail stores, built with React, Vite, and Redux Toolkit.

## Modules

- **Cash Register (`/pos`)**: High-speed checkout, barcode item scanning, multi-tier discounts (standard, custom, and multi-item), bottle deposit surcharges, and order hold & resume.
- **Backoffice (`/backoffice`)**: Product catalog management, unit variation stock tracking (Single, 6-Pack, Case), employee roles, and transaction history.

## Getting Started

### Prerequisites

- Node.js >= 18
- npm >= 9

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

The application runs on `http://localhost:5173/`.

### Building for Production

```bash
npm run build
```
